# 学校资料库 1.0

面向分校校长和学校攻坚小组的单校资料索引，集中回答：有什么资料、原文在哪里、还缺什么。

## 运行

使用最新版 Edge 或 Chrome 直接打开 [`index.html`](index.html)，无需安装、构建或启动服务。

页面包含学校概况、可搜索和按五类筛选的资料清单，以及直接可见的缺失资料。当前内容均为匿名演示数据，原文链接带有“演示”标记。

## 文件

- `index.html`：页面、样式、交互和JavaScript演示数据
- `handoff.md`：当前状态与数据维护说明
- `AGENTS.md`：开发、验证与发布约束
- `artifacts/school-archive-desktop.png`：Chrome桌面端验收截图
